# Security Policy

Supported: the latest released version of each gem.

Report a vulnerability by email to apavlovskiy088@gmail.com, not in a public issue. Include the gem and
version, how to reproduce, and the impact. You will get an answer within a week; a fix is released as a patch
version and the advisory is published after it.

Credentials never appear in logs, instrumentation payloads or `inspect` output by design; a report that shows
otherwise is a vulnerability.
